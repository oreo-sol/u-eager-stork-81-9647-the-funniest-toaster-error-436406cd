A one-line error message a kitchen toaster shows its owner when the lever jams — deadpan, in the voice of a small appliance that has decided to negotiate.

> ERROR: Lever jammed. Your breakfast is being held hostage. I have no demands.

## Run

```sh
node main.ts
```

This writes the line to `/output/entry.txt`.
